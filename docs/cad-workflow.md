# Authorized local CAD workflow

The supplied application runs without CAD files. For authorized local work, the 2027 plugin can inspect selected supported objects using a temporary local DXF snapshot. The browser also accepts supported local DXF; convert DWG using an authorized CAD tool first. Preserve source units, WCS coordinates, source handles, instance paths, drawing identity, and revision. An inspection candidate is not an approved semantic pipe connection. Do not commit private source geometry or derived outputs.
