# PipeForge Edge: 90-second demonstration

Use the companion/file-exchange workflow on this Linux instance. Native AutoCAD needs the separate Windows checks in [AUTOCAD.md](AUTOCAD.md). The target is regular AutoCAD; the actual release remains unknown. A real DWG, Autodesk runtime and physical Qualcomm execution have not been verified here.

Start the application with `./scripts/start.sh` in the prepared workspace, then open port 8000. For a Windows installation, use the local PowerShell setup/start scripts described in [REMOTE.md](REMOTE.md). Prepare the **B · Congested machinery** scenario. The warning, route, measured clearance and latency displayed during the demonstration must come from this run.

| Time | Action | What to explain |
| --- | --- | --- |
| 0–12 s | Select **CAD companion**. In **Edge companion**, enter a drawing identifier and select **Connect workspace drawing**. | The session is tied to a drawing identity and revision. A JSON/DXF import can replace the fixture; DXF needs explicit engineering metadata. Unmapped CAD handles remain unverified. |
| 12–27 s | Select **Analyze revision**, then select a collision finding. | The viewer highlights the selected route; the finding identifies source object IDs, location, measured separation and configured requirement. Red indicates an evaluated violation; amber identifies missing information. |
| 27–47 s | Select **Propose route**. | Routing runs in a background job against the source revision, other systems and fixed environment. Show the actual processing time and local/remote execution label. |
| 47–64 s | Select the candidate and **Preview proposal in 3D**. | Cyan is a preview. Inspect original/proposed metrics and independent validation. A congested route may become longer while removing clashes. Check the remaining UNVERIFIED requirements. |
| 64–78 s | Enter **Reviewing engineer** and a comment; select **Approve proposal**. | This records a durable designer decision. It preserves the source snapshot and does not write the original CAD drawing. Rejection is available instead. |
| 78–90 s | Download an approved **JSON**, **DXF**, **CSV** or **REPORT**; open **Revision & decision audit**. | The package contains source/proposed geometry and review evidence. The engineer reviews instructions in CAD. An edit invalidates older results and export approval. |

For an identity demonstration, import a real handle map in **CAD object identity**. Do not present fixture identifiers as extracted AutoCAD handles. JSON engineering model coordinates and metadata dimensions are meters. DXF exchange converts supported declared drawing units and records real entity handles; a unitless DXF requires **DXF source units** to be selected explicitly. The reviewed JSON package includes the checked source scale and source-unit modification instructions. Native connector unit conversion must still be checked on the actual drawing.

To demonstrate monitoring in a workspace-owned session, enable **Live sync · 400 ms** and **Live analyze after sync**, make a supported workspace model edit, and show the revision advance. Alternatively, use **Sync workspace edits (N)**. The browser transmits the changed object delta. Analysis cache counts distinguish reused routes from recomputed routes; nearby surrounding systems remain constraints. A preview is not treated as a source edit.

For a native connector session, use **Existing CAD session ID → Attach CAD session**, or open `http://127.0.0.1:8000/?edge_session=SESSION_ID`. This attaches to the same authoritative model without creating another revision. Make source edits in CAD. The browser checks lightweight status periodically and fetches a snapshot when revisions or review events change; **Refresh CAD session** is also available manually. A new source revision clears older findings while preserving the viewport; **Load latest source view** explicitly updates it. Use **Create what-if session** for an independent exploratory copy. Native sessions do not enable workspace source synchronization.

Remote processing is optional. Start the CPU worker using [REMOTE.md](REMOTE.md), select **Remote worker**, enter its address and select **Check worker**. Use the execution label and measured round-trip/compute values. An unavailable or invalid worker falls back locally and reports that outcome. A same-machine loopback test demonstrates transport behavior; it does not establish a Qualcomm speedup.

For native AutoCAD after the Windows smoke test succeeds: `PFCONNECT` binds mapped entities and metadata; `PFCOMPANION` opens the exact shared session URL. `PFANALYZE` / `PFOPTIMIZE` start work, `PFHIGHLIGHT` focuses issues, `PFPREVIEW` shows transient route geometry, `PFAPPROVE` / `PFREJECT` record review, and `PFEXPORT` writes a new exchange file. After browser review, `PFREFRESH` retrieves the current proposals and approval state for native preview/export. It refuses pending native edits and stale replies. `PFLIVEON` enables debounced automatic analysis; `PFLIVEOFF` stops it. Optimization remains explicit. These commands are a runbook, not evidence of native execution in this environment.
