# Routing implementation

The team route engine remains in `pipe_router/core.py` and `pipe_router/workflow.py`. Connected coordination extends that engine in `pipe_router/connected.py`, while `network_validation.py` independently checks the full proposed network. Search budgets bound work; unsuccessful bounded search is not proof of global infeasibility.
